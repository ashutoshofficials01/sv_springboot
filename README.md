# ScanVera - Backend (Spring Boot)

Resume Storage & Management Backend. Secure APIs for uploads, storage, CRUD, filtering with MySQL.

## 🚀 Features
- RESTful endpoints (/resumeUpload, /login, /fetch)
- File storage 
- File handling & validation 
- MySQL integration 
- Exception handling 

## 🛠️ Tech Stack
| Backend | Database/Tools |  
|---------|----------------|  
| Spring Boot, Java | MySQL, Maven, Postman |  

## ⚙️ Quick Setup
1. `git clone https://github.com/ashutoshofficials01/svSpringboot.git`  
2. Update `application.properties` (DB creds, server.port=8082)  
3. `mvn spring-boot:run` → http://localhost:8082  

**Frontend:** [svAngular](https://github.com/ashutoshofficials01/svAngular)
